🚀 Getting Started

Clone the repo and install dependencies:

bash
git clone git@github.com:markifornia/svelte-projects.git
cd svelte-projects/learn-svelte
npm install

Run the dev server:

bash
npm run dev

Then open the local URL shown in your terminal (usually http://localhost:5173).
